that none of it is still offered on a screen (button, link, tab, field, download, label), written into
an instruction a reader sees, or counted as a completion condition. Where a retired thing leaves a
residue the rulings allow (past runs, stored files, code kept wired), the "Still allowed" column says
so, so that residue is not reported as a defect. Signal is out of scope and has no row.

Section ids are those of `output/0-baseline/sections.md`. Rows of `content-matrix.csv` and
`control-matrix.csv` that carry the same expectation are named in the last column.
